# 🧭 Truesight Tracker

This repository is the **public hub for issues and changelogs** for Truesight.world.  
It exists to give creators, testers, and community members a single place to:

- Report bugs
- Request features
- Track known issues
- Follow release notes and updates

No source code or assets are stored here.
This repo is purely for **communication, transparency, and feedback**.

## 📣 How to Use This Repo

### **1. Check existing issues**
Before creating a new issue, see if someone has already reported it.

### **2. Create a new issue**
If it’s new, open an issue with:
- A clear title  
- Steps to reproduce (if applicable)  
- Expected vs. actual behavior  
- Screenshots or logs (optional)

### **3. Follow releases**
Stay updated by watching the repository or checking the Releases tab.
